Segment Details
99
Prefix
Fixed coupon prefix. Always 99 for in-store coupon/voucher barcodes under the GS1 standard.
Position 1–2 · 2 digits · Fixed
XXXX
Issuer Code
Identifies the company or manufacturer that issued the coupon. This is a unique 4-digit code assigned to the retailer.
Position 3–6 · 4 digits · Variable
NNN
Offer Reference
A unique reference number for the specific offer or promotion. Used to distinguish between different deals from the same issuer.
Position 7–9 · 3 digits · Variable
VVV
Value
The monetary value encoded in the barcode. Typically represents the value in the smallest currency unit (e.g. pence).
Position 10–12 · 3 digits · Variable
C
Check Digit
Automatically calculated using the EAN-13 checksum algorithm. Ensures the barcode is valid and can be scanned correctly.
